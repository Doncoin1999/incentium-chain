# Incentium address format (SS58 prefix 122)

Incentium accounts are shown with SS58 prefix **122**, so every address starts with `ic`
(for example `icy7AAYp8jbLwGuSLJ24dWJQmpVoRWJG8nwXjiHnsvwd8mn5T`). The keys are ordinary
sr25519/ed25519 keys: `ic...` and the generic `5...` form of the same key are one account, and the
faucet, registration service and miners accept both.

About one address in five starts with `ict` by chance; project accounts (operator, curator,
faucet) can be generated until they do.

## Registering the prefix

The prefix is registered in Parity's SS58 registry (https://github.com/paritytech/ss58-registry)
so wallets and libraries recognise it:

1. Fork the repository, check that 122 is still free in `ss58-registry.json`.
2. Add this entry in prefix order:

```json
{
  "prefix": 122,
  "network": "incentium",
  "displayName": "Incentium",
  "symbols": ["ICT"],
  "decimals": [9],
  "standardAccount": "*25519",
  "website": "https://incentium.org"
}
```

3. Bump the minor version in `Cargo.toml`, commit, and open a pull request.
